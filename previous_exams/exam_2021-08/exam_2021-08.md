# Question 3: Intervals (7p)

Similar to vectors and complex numbers, we can have other numerical types, like an `Interval`; which represents an set of numbers between a given `low` and `high` limit.
We may use such a numeric type in our code to represent quantities which we have error bars on our measurements: e.g:

> A thrown ball has a estimated velocity between `10` and `11` m/s, and it travels for between `5` and  5.5` seconds. How far will could it travel?
> With the given estimates it will be at least $10\times 5 = 50$ m and at most $11\times 5.5 = 60.5$ m.

or shorter `Interval(10,11) * Interval(5, 5.5) == Interval(50, 60.5)`.

When doing math on intervals we can think of it as computing every possible value and compute the spread of the output.
Just like multiplication above we can do the same for addition, subtraction etc. which will let us have a very powerful tool!

## Part A (1p)

Write a class `Interval` which a constructor that takes a `low` and `high` value.
This object represents all the numbers between `low` and `high` (inclusive), so make sure the input makes sense; throw the appropriate builtin exception if `high` is smaller than `low` with an appropriate message.

## Part B (0.5p)

Add support for `repr` to make our custom type more convenient when debugging or printing.

## Part C (0.5p)

Add a method `overlaps` that takes another interval and returns true if they overlap (else false).

## Part D (3p)

Implement support for the common operators: negation ($-x$), addition ($x+y$), and substraction ($x-y$).
The output should be a new `Interval` with the correct `low` and `high` values.

We should think of the operations as; *What are the range of numbers that could appear if I combine any values in the intervals from $x$ and $y$?*

1. When we negate an interval it changes signs, as well as the high and low switch places `-Interval(-3, 10) == Interval(-10, 3)`
2. Addition is simple; the `low` and `high` values simply add up respectively.
3. Subtraction is like a combination of negation and addition $x-y = x+(-y)$. 

## Part D (1p)

Implement support for multipication between intervals: $x*y$.

This can get *a bit* tricky when negative numbers appear! With some careful reasoning we can deduce that the `low`est and `high`est values must be one of the 4 possible products from the limits of $x$ and $y$. 

## Part E (1p)

Implement support for absolute values values $abs(x)$.

Note: Something interesting happens when an interval includes crosses the 0 boundary! E.g.
What is the `low`est value you can obtain if you take the absolute value of all numbers between $-4$ and $5$? $0$.
What is the `low`est value you can obtain if you take the absolute value of all numbers between $-15$ and $-4$? $4$.
What is the `high`est value you can obtain if you take the absolute value of all numbers between $-10$ and $9$? $10$.

## Example

```python
x = Interval(1., 3.)
y = Interval(-4., 5.)
z = Interval(-10., 0.)

print('x overlaps z =', x.overlaps(z))
print('y overlaps z =', x.overlaps(y))
print('-x = ', -x)
print('-y = ', -y)
print('-z = ', -z)

print('x + y =', x+y)
print('x - y =', x-y)
print('z - x =', z-x)

print('x * y =', x*y)
print('z * y =', z*y)
print('y * y =', y*y)

print('abs(x) =', abs(x))
print('abs(y) =', abs(y))
print('abs(z) =', abs(z))
```

# Question 4: Generator vectors (8p)

You must solve this problem without using `numpy` or `scipy`.

Sometimes we need to create very large arrays in memory constrained environments.
One common trick that is sometimes applicable is to lazily evaluate the contents of the array, as it is accessed.
The point of these as that they don't allocate memory up front. 

## Part A (2p)

Write an abstract base class `GeneratorVector` that stores the length of the array and support the builtin `len(v)` function.

1. It should enforce the `__getitem__` method as abstract.
2. It should implement a method `collect()` which returns all the vector values as a standard python `list`.

## Part B (2p)

## Part C (2p)
