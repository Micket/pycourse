# Computer exam

Files are located under `C:\__EXAM__\`

## Starting jupyter notebook:

1. Search in the start menu for "Anaconda prompt" and launch it.
2. Run `cd C:\__EXAM__`
3. Run `jupyter notebook`
4. Navigate to Lectures for the lecture notes.

## Starting PyCharm with Anaconda Python:

1. When starting a new project, select "Previously configured interpreter"
2. Select "System Interpreter"
3. If Anaconda (3) isn’t listed in the options, select a new one.
4. It is located under `C:\ProgramData\Anaconda3\python.exe`
   Note that `C:\ProgramData` is hidden; you must show hidden files.

## Show the computer host name

1. Open another command prompt / anaconda prompt
2. Run `hostname`
3. Write the hostname on the exam cover, make sure it is visible even when your name is hidden. Make sure the exam host verifies the hostname.
