# Question 2: Musical analysis (Xp)

You are prototyping an Python based musical tuning program for a well known Viloin manufacturer. The company has sent over a test recording of a viloin, see the file `violin.wav` and your boss has given you the task to implement two parts of the project.

Part A (2p)
-------------

**Task:** Implement a function `pitch` that takes a floating point value `frequency`, in the unit of Hertz (Hz), as input and returns a text string with the corresponding musical tone and octave. Remember to document the function.


**Example:** The frequency 440 Hz corresponds to A4, were A denotes the tone and 4 denotes the octave. Here is an example usage of the function `pitch`
```python
freqency = 440. # unit Hertz
print(pitch(frequency), '=', frequency, 'Hz')
```
should give the result
```
A4 = 440.0 Hz
```

**Background:** Converting a frequency $f$ in Hertz to $n$ note and $o$ octave can be done by computing the value
$$ h = 12 \cdot \log_2 ( f / f_{C0}) $$
were $f_{C0}$ is the frequency for the note C0 which is given by $f_{C0} = f_{A4} \cdot 2^{-4.75}$ were $f_{A4} = 440\,$Hz. Let $[h]$ denote the integere closest to $h$, then the octave $o$ is given buy the result of the integer division, $o = [h] / 12$ and the index of the note $n$ is given by the remainder of the integer division with $12$, $n = [h] % 12$. To map the note index $n$ to actual notes use the list of notes: [C, C#, D, D#, E, F, F#, G, G#, A, A#, B].

**Hint:** use the `log2` and `round` functions from the `math` module of the Python standard library, or the equivalent NumPy functions.

Part B (2p)
-----------

**Task:** Write a program that reads the sound file `violin.wav` and plots the sound amplitude data as a function of time, using *seconds* as the time unit.

**Hints:** 

* To read the file use a suitable part of the `scipy.io` module, see the SciPy documentation. 
* The sound data has two components, 
  * the amplitude $A(t)$, as a function of time $t$, and 
  * the sample rate $R$, given in the unit of Hz, determining the number of aplitude data points per second.
* The time $t_i$ of the data point with index $i$ is given by $t_i = i/R$. 
* Use Matplotlib for plotting and make sure to add x- and y-labels including information on units.

Part C (4p)
-----------

**Task:** Determine the dominating frequency in the sound file `violin.wav` and use your `pitch` function to compute the corresponding musical note. Do this by *computing* and *plotting* the amplitude of the sound as a function of frequency (instead of time). Use a suitable NumPy function to find the maximum amplitude in frequency and use this frequency as input to your `pitch` function, to compute and print the corresponding musical note.

**Hints:**

- The amplitude of the sound $A(v)$ in frequency $v$ can be computed by taking the absolute value of the Fourier transform $\mathcal{F}\{ \cdot \}$ of the amplitude as a function of time $A(v) = | \mathcal{F}\{ A(t) \} |$.
- To compute $\mathcal{F}\{A(t)\}$ use the `numpy.fft.fft` function, and to compute $v$ use the `numpy.fft.fftfreq` function.

# Question 3: A simple inventory (6p)

You want to use Python to help you keep track of your groceries and decide to create a class representing the inventory.

Part A (3p)
-------------
You decide that you need a helper class to represent the items in the inventory, therefore create the class `InventoryItem`
with the following contructor:

`InventoryItem(name: str, storage: StorageType, unit: StorageUnit)`

Make the constructor have `Standard` as the default `StorageType` and `pieces` as the default `StorageUnit`.


Here `StorageType` must be an `Enum` type and have at least the choices `Standard`, `Cold` and `Freezer`.

And `StorageUnit` mut be an `Enum` type and have at least the choices `kg`, `liter`, `cans` and `pieces`.


For `InventoryItem` implement the following methods:
* `<`: Compare on the item name
* A suitable method to be able to use `print()` on an object of this type

Part B (2.5p)
-----------

Implement the class `Ìnventory`, its constuctor should take the inventory name as a parameter.

Implement the following methods for `Inventory`:
* `add(item: InventoryItem, amount: int or float)`
* `remove(item: InventoryItem, amount: int or float)`
* A suitable method to be able to use `print()` on an object of this type


*Hint: If you want to use an `InventoryItem` as a key, you need to implment the `__hash__` method for that class.
       The name can be used as a key for hash()-ing on!*


Part C (0.5p)
-----------
Add code so that the `add` and `remove` methods should raise suitable errors if a to small or large `amount` is given, or the
item to remove is not found in the inventory.



Example code:
```python
inv = Inventory('Kitchen')
print(inv)

beans = InventoryItem('Beans', unit=StorageUnit.cans)
rice = InventoryItem('Rice', unit=StorageUnit.kg)

inv.add(beans, 4)
inv.add(rice, 0.5)
inv.add(egg, 6)
print(inv)

inv.remove(beans, 2)
inv.remove(egg, 1)
print(inv)

try:
    inv.remove(InventoryItem('Concrete'))
    print(f'Wow, did we store concrete in the {inv.name}!')
except NameError:
    print(f'No concrete in the {inv.name}!')

try:
    inv.remove(egg, 10)
    print(f'Wow, plenty eggs in the {inv.name}!')
except ValueError:
    print(f'Not enough eggs in the {inv.name}!')
```

# Question 4: Class hierarchy for shapes (8p)

As part of creating an application for making presentations, we are tasked with implementing support for adding simple shapes that can be moved and rotated.

For convenience, we can use numpy arrays to perform the transformations inside the different shape types.

Part A (2.5p)
-----------
Write a base class `Shape` that stores the `centre` position of the shape. It should have:

- The method `.move(distance)` that moves the whole shape by the given distance vector.
- The abstract method `.resize(scale)` that scale the whole shape around the centre point.
- The abstract method `.rotate(theta)` that rotates whole shape around the centre point.
- The abstract method `.bounding_box()` that computes the lower left and upper right coordinates of the rectangle/box that covers the shape.

Part B (2.5p)
-----------
Write the subclass `Circle` which represents a perfect circle. Its constructor should take the centre point coordinate, and a radius.

Part B (3p)
-----------
Write the subclass `Polygon` which represents the lines looped through a set of points.
Its constructor should take a numpy array of nodes, but store its values relative to the centre (defined by the average of all nodes).
