# Question 3: A simple inventory (6p)

You want to use Python to help you keep track of your groceries and decide to create a class representing the inventory.

Part A (3p)
-------------
You decide that you need a helper class to represent the items in the inventory, therefore create the class `InventoryItem`
with the following contructor:

`InventoryItem(name: str, storage: StorageType, unit: StorageUnit)`

Make the constructor have `Standard` as the default `StorageType` and `pieces` as the default `StorageUnit`.


Here `StorageType` must be an `Enum` type and have at least the choices `Standard`, `Cold` and `Freezer`.

And `StorageUnit` mut be an `Enum` type and have at least the choices `kg`, `liter`, `cans` and `pieces`.


For `InventoryItem` implement the following methods:
* `<`: Compare on the item name
* A suitable method to be able to use `print()` on an object of this type

Part B (2.5p)
-----------

Implement the class `Ìnventory`, its constuctor should take the inventory name as a parameter.

Implement the following methods for `Inventory`:
* `add(item: InventoryItem, amount: int or float)`
* `remove(item: InventoryItem, amount: int or float)`
* A suitable method to be able to use `print()` on an object of this type


*Hint: If you want to use an `InventoryItem` as a key, you need to implment the `__hash__` method for that class.
       The name can be used as a key for hash()-ing on!*


Part C (0.5p)
-----------
Add code so that the `add` and `remove` methods should raise suitable errors if a to small or large `amount` is given, or the
item to remove is not found in the inventory.



Example code:
```python
inv = Inventory('Kitchen')
print(inv)

beans = InventoryItem('Beans', unit=StorageUnit.cans)
rice = InventoryItem('Rice', unit=StorageUnit.kg)
egg = InventoryItem('Egg', storage=StorageType.Cold)
inv.add(beans, 4)
inv.add(rice, 0.5)
inv.add(egg, 6)
print(inv)

inv.remove(beans, 2)
inv.remove(egg, 1)
print(inv)

try:
    inv.remove(InventoryItem('Concrete'))
    print(f'Wow, did we store concrete in the {inv.name}!')
except NameError:
    print(f'No concrete in the {inv.name}!')

try:
    inv.remove(egg, 10)
    print(f'Wow, plenty eggs in the {inv.name}!')
except ValueError:
    print(f'Not enough eggs in the {inv.name}!')
```

# Question 4: Class hierarchy for shapes (8p)

As part of creating an application for making presentations, we are tasked with implementing support for adding simple shapes that can be moved and rotated.

For convenience, we can use numpy arrays to perform the transformations inside the different shape types.

Part A (2.5p)
-----------
Write a base class `Shape` that stores the `centre` position of the shape. It should have:

- The method `.move(distance)` that moves the whole shape by the given distance vector.
- The abstract method `.resize(scale)` that scale the whole shape around the centre point.
- The abstract method `.rotate(theta)` that rotates whole shape around the centre point.
- The abstract method `.bounding_box()` that computes the lower left and upper right coordinates of the rectangle/box that covers the shape.

Part B (2.5p)
-----------
Write the subclass `Circle` which represents a perfect circle. Its constructor should take the centre point coordinate, and a radius.

Part B (3p)
-----------
Write the subclass `Polygon` which represents the lines looped through a set of points.
Its constructor should take a numpy array of nodes, but store its values relative to the centre (defined by the average of all nodes).
