Question 1: Practice sheet for Swedish verbs (6p)
=================================================

You have a file with Swedish verbs that you want to learn. To help you practice you want to parse this file and print out a
table with random set of verbs and a random form of each verb. Then you can practice by filling out the other forms.
You also want to print the full table to be able to verify your results.

The file `verblista.txt` contains one verb per line and it's (at most) five different forms.
Typical lines can look like this:
```
    övervinn!   övervinna   övervinner  övervann   övervunnit
         bosätt! (sig)      bosätta (sig)     bosätter (sig)     bosatte (sig)     bosatt (sig)
              angrip!           angripa          angriper          angrep           angripit
              ---              avlida           avlider           avled            avlidit
```

As you can see there are different numbers of blanks between verb forms, but there are at least two blanks between verb forms.
Also `---` indicates that this verb does not have that for.

Part A (1p)
---------------
Write a function `parse_line(line: str) -> tuple` that takes a string representing one line like the ones above and returns tuple with the five entries.
If a verb form is not present, a `None` should be on that position in the tuple.

**Example:**
```python3
verb = parse_line("---              avlida           avlider           avled            avlidit")
print(verb)
```
**Output:**
```text
(None, "avlida", "avlider", "avled", "avlidit")
```

Part B (0.5p)
-------------
Write a function `read_file(filename: str) -> list` that reads the file and uses the function `parse_line` to convert lines to tuples
and finally returns a list of all the tuples representing a verb.

Part C (1p)
---------------
Write a function `select_verbs(count: int, verbs: list[tuple]) -> list[tuple]` that takes a list of verbs and selects `count` random unique
verbs from the list and returns them in a new list.

Part D (0.5p)
---------------
Write a function `select_form(verb: tuple) -> int` that takes a verb tuple as an input and returns the index of a random chosen __valid__
verb form (i.e. not `None`).

For example for the verb in the Part A example, 1 - 4 would be valid indices, but not 0.

Part E (1.5p)
---------------
Write a function `print_practice_sheet(verbs: str) -> None` that prints out a practice form. It should use `select_form` to select a random
form for each verb.

The form should be formatted as in the example below, with proper column widths, borders and separators.
Use 8 characters as a minimum word length.

**Example output for random 10 verbs:**
```text
=========================================================
|          |          |          |          | förutsatt |
|          |          |          | valde    |           |
|          |          |          |          | förbjudit |
| spinn!   |          |          |          |           |
|          |          | avlider  |          |           |

|          |          |          | slog     |           |
|          |          |          | borde    |           |
| föreslå! |          |          |          |           |

```
