Question 1: Practice sheet for Swedish verbs (6p)
=================================================

You have a file with Swedish verbs that you want to learn. To help you practice you want to parse this file and print out a
table with random set of verbs and a random form of each verb. Then you can practice by filling out the other forms.
You also want to print the full table to be able to verify your results.

The file `verblista.txt` contains one verb per line and it's (at most) five different forms.
Typical lines can look like this:
```
    övervinn!   övervinna   övervinner  övervann   övervunnit
         bosätt! (sig)      bosätta (sig)     bosätter (sig)     bosatte (sig)     bosatt (sig)
              angrip!           angripa          angriper          angrep           angripit
              ---              avlida           avlider           avled            avlidit
```

As you can see there are different numbers of blanks between verb forms, but there are at least two blanks between verb forms.
Also `---` indicates that this verb does not have that for.

Part A (1p)
---------------
Write a function `parse_line(line: str) -> tuple` that takes a string representing one line like the ones above and returns tuple with the five entries.
If a verb form is not present, a `None` should be on that position in the tuple.

**Example:**
```python3
verb = parse_line("---              avlida           avlider           avled            avlidit")
print(verb)
```
**Output:**
```text
(None, "avlida", "avlider", "avled", "avlidit")
```

Part B (0.5p)
-------------
Write a function `read_file(filename: str) -> list` that reads the file and uses the function `parse_line` to convert lines to tuples
and finally returns a list of all the tuples representing a verb.

Part C (1p)
---------------
Write a function `select_verbs(count: int, verbs: list[tuple]) -> list[tuple]` that takes a list of verbs and selects `count` random unique
verbs from the list and returns them in a new list.

Part D (0.5p)
---------------
Write a function `select_form(verb: tuple) -> int` that takes a verb tuple as an input and returns the index of a random chosen __valid__
verb form (i.e. not `None`).

For example for the verb in the Part A example, 1 - 4 would be valid indices, but not 0.

Part E (1.5p)
---------------
Write a function `print_practice_sheet(verbs: str) -> None` that prints out a practice form. It should use `select_form` to select a random
form for each verb.

The form should be formatted as in the example below, with proper column widths, borders and separators.
Use 8 characters as a minimum word length.

**Example output for random 10 verbs:**

Question 2: Maximising sales value (5p)
=======================================
A store has requested a manufacturer to produce pants and sports jackets.

For materials, the manufacturer has $750 m^2$ of cotton textile and $1000 m^2$ of polyester. Every pair of pants (1 unit) needs $1 m^2$ of cotton and
$2 m ^2$ of polyester. Every jacket needs $1.5 m^2$ of cotton and $1 m^2$ of polyester.
The price of the pants is fixed at 50 and the jacket 40.

What is the number of pants and jackets that the manufacturer must give to the stores so that these items obtain a maximum sales value?

Part A (2p)
---------------
Formulate this problem as a linear programming problem.

Start by using $x$ as the number of pants and $y$ as the number of jackets and formulate the objective function $f(x, y)$.

Then formulate constraints for cotton and polyester. What are the constraints on $x$ and $y$?

The answer should be written either as code or clear comments in a doc string. Please note that that code versions of these are needed for Part B. 

Part B (3p)
---------------
Using the Linear Programming solver found in SciPy, set up and solve the problem, i.e. solve for $x$ and $y$.

Print the resulting $x$, $y$, and total sales value, with suitable labels. Please round no. of units to an integer.


Question 3: Bijection (6p)
==========================
A bijection, also known as a one-to-one correspondence, is a mapping between the elements of two sets, where each element of one set is paired with exactly one element of the other set, and each element of the other set is paired with exactly one element of the first set.
There are no unpaired elements.

Part A (1.5p)
---------------
Create the class `Bijection` that represent the one-to-one mapping between elements as described above. Compare with a dictionary that contains mappings between a key and a value (but several keys can give the same value).

The constructor must be able to handle both an empty argument, and a list/tuple of tuples of two values to (double-) map.

Also create a method `add` that adds one item to the Bijection. The method must make sure that both values/keys are unique and raise a suitable exception
if called with non-unique data. (Using this method can simplify the constructor.)

Part B (1p)
---------------
Create a method `map_forward` that takes as an argument a value/key from the first set and returns the mapped value/key from the second set, and the
corresponding method `map_backward` that does the opposite, i.e. takes as argument a value/key from the second set and returns the mapped value/key
from the first set.

Part C (1p)
---------------
Add an iterator for the `Bijection` class. This iterator should return one tuple of mapped items at a time.

Part D (0.5p)
---------------
Add the methods for displaying and converting a `Bijection` object to a string (repr and str), see the example below.

Part E (2p)
---------------
Add a method `delete(first=None, second=None)` to the class. This method must only allow for exactly one of `first` or `second` to be set and raise an
exception otherwise. If the value/key set is present in the corresponding set the `Bisection` element should be deleted. If it is not present in any of
the sets a suitable exception should be raised.

**Examples:**
```python3
db = Bijection()
db2 = Bijection((('a', 1), ('b', 2)))

db.add(('a', 1))
db.add(('b', 2))
db.add(('c', 3))

assert db.map_forward('b') == 2
assert db.map_backward(1) == 'a'

for a, b in db2:
    print(a, '<-->', b)

print()
print(db)
db.delete(second=3)
print(db)
```
**Output:**
```text
a <--> 1
b <--> 2

{a::1, b::2, c::3}
{a::1, b::2}
```

Question 4: Dataset hierarchy (7p)
===================================
In machine learning we often need to train models where the data is stored in many different ways, for example in memory, files on disk, or a database.
Here we will write a class hierarchy that unifies access to those different methods.

Part A (1.5p)
---------------
Write an abstract base class `Dataset` which stores a `name` as an instance variable and implements the method `rand` for fetching a random element from the dataset.
It should enforce the abstract methods for computing the `len(dataset)` and getting an item using with `dataset[i]`

*Hint: `random.randrange` is useful here.*

Part B (1p)
---------------
Implement the subclass `ListDataset` which takes a `name` and list of `data` as input.
Add a nice `repr` method.

Part C (1.5p)
---------------
Implement the subclass `DirectoryDataset` which only takes a path to a directory as input.
It's name should be the last directory in the given path: `examples/limerick` should produce the name `limerick`.
Add a nice `repr` method.

The examples are small, but the idea here is to read the `i`-th file accessing `dataset[i]` as it's to large to fit in all of it in memory.

*Hint: `os.listdir` is useful here.*

Part D (2p)
---------------
We often need to split a dataset into parts for training and validation. 
Implement the subclass `SubsetDataset` which takes another `dataset` and a `subrange` (like `range(1, 3)`)
It should not make any copies of the input data.
The name of the subset should be the same as the dataset it captures.
Add a nice `repr` method.

Part E (1p)
---------------
For testing behaviour its often useful to have random data.
Implement the subclass `RandomDataset` which takes takes a `name` as input.
It should just report `1` as the length of the dataset and getting an item with `dataset[0]` should generate a random lowercase string with 10 characters.

*Hint: random.choice is useful here*

Please see below and look at the file `question4_test.py` for examples and tests.

\newpage

```python3
# Tests
a = ListDataset('test strings', ["some", "simple", "example", "strings", "are", "always", "easy", "to", "test", "with"])
b = DirectoryDataset('example/poems')
c = DirectoryDataset('example/limericks')
d = SubsetDataset(a, range(1,7,2))
e = RandomDataset('testing')

assert a[1] == "simple"
assert b[2].startswith("There once was a text editor called PyCharm")
assert c.name == "limericks"
assert d.name == "test strings"
assert d[2] == "always"
assert len(c) == 6  # 6 example limericks
assert len(d) == 3
assert len(e.rand()) == 10 and type(e.rand()) == str  # should be a random 10 character string

print(a.rand())
print(b.rand())
print(c.rand())
```
