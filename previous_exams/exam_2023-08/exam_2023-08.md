# Question 1: Detecting file tampering (6p total)

A common security technique, for ensuring that no malicious attacker have managed to tamper with important files, is to
generate so called "checksums" or "hashes" for all files. These are short, almost unique strings computed with an
algorithm that makes it's very hard to insert changes to any file without also modifying the hash.

Using multiple hash-algorithms makes the likelihood of an attacker sneaking in an attack even less likely.

Part A (3p)
-----------

You have been given a file containing hashes for a couple of files, `checksums.txt`.
The format of this file is;
```text
"path to file"  hash_algorithm:hash_in_hex  hash_algorithm:hash_in_hex
...
```
A file can have one or more different hashes.

Write a function `read_checksums` that takes a filename as argument, parses the given file and returns a dictionary that
maps paths to a dictionary of hashes.

```python
>>> checksums_db = read_checksums('checksums.txt')
>>> print(checksums_db)
{'testfiles/correcting_exams.png': {'md5': 'eaee750...', 'sha256':'a53f94...'}, 
...
}
```

*Hint: `defaultdict` from `collections` may be useful.*

Part B (3p)
-----------

Write a function `verify_files` that takes the dictionary from part A and verifies all the checksums listed.
If a file is missing, print a helpful error that an attacker might have deleted it, then proceed with the rest of
the files.
If the hash doesn't match, print a message that shows filename, algorithm and the mismatched hashes.

```text
>>> verify_files(checksums_db)
Error! "testfiles/filename with spaces.txt" differs from md5:83b0a... (eecc...)
Error! "testfiles/filename with spaces.txt" differs from sha256:152b... (f54b...)
Error! "testfiles/another dir/missing.txt" missing
```

Use the `hashlib` module to compute the actual hashes of the file contents.
You want to use the `hexdigest` method (because the hashes in `checksums.txt` are also stored as hex strings).

*Hint: hashlib digest command expects binary data, so you should `open` the files in binary mode.*

*For testing, you may move the `testfiles` to your working directory, or use relative paths if you prefer, but don't
alter the directory contents.*

# Question 3: Intervals (6p)

Similar to vectors and complex numbers, there exists other useful numerical types, like an `Interval` which represents the set of numbers between a given `low` and `high` limit.
We may use such a numeric type in our code to represent quantities for which we have error bars on our measurements, for example:

> A thrown ball has a estimated velocity between $10$ and $11$ m/s, and it travels for between $5$ and $5.5$ seconds. How far will it travel?
> With the given estimates it will be at least $10\times 5 = 50$ m and at most $11\times 5.5 = 60.5$ m.

or in code: `Interval(10, 11) * Interval(5, 5.5) == Interval(50, 60.5)`

When doing maths on intervals we can think of it as computing every possible value and compute the spread of the output; what is the lowest and highest values you can obtain.
Just like multiplication above we can do the same for addition, subtraction, etc., and we end up with a very powerful tool allowing us to keep track of the accuracy in our computations!

## Part A (1p)

Write a class `Interval` with a constructor that takes a `low` and `high` value.
This object represents all the numbers between `low` and `high` (inclusive), so make sure the input makes sense; raise an appropriate builtin exception if `high` is smaller than `low` with an informative message.

## Part B (0.5p)

Add support for `repr` to make our custom type more convenient when debugging or printing (see examples).

## Part C (0.5p)

Add a method `overlaps` that takes another interval and returns $True$ if they have any overlap (otherwise $False$).

## Part D (0.5p)

Add support for converting the `Interval` to a `float`, returning the mean value.

## Part E (2p)

Implement support for the common operators: negation ($-x$), addition ($x+y$), and subtraction ($x-y$).
The output should be a new `Interval` with the correct `low` and `high` values.

We should think of the operations as; *What are the range of numbers that could appear if I combine any values in the intervals from $x$ and $y$?*

1. Addition is simple; the `low` and `high` values simply add up respectively to form the new interval (no need to handle negative numbers differently).
2. When we negate an interval it changes signs, as well as the high and low switch places `-Interval(-3, 10) == Interval(-10, 3)`
3. Subtraction is like a combination of negation and addition $x-y = x+(-y)$. 

## Part F (1.5p)

This can get *a bit* tricky when negative numbers appear. What is the `low`est and `high`est numbers you can construct from the interval $x$ and $y$? There are only 4 possible extremes!



# Question 4: HTML elements (7p)

HTML is a markup language used for web-pages that allows you to control layout and design.

The general syntax uses an opening `<x>`, followed by content, and finally a closing `</x>`.
Additional data fields can be added to the opening block, e.g:
`<a href="www.chalmers.se" style="color:red">a link to Chalmers</a>`

Blocks typically contain each other in a hierarchy, meaning one block can contain another.

To model this in code, we will introduce a hierarchy of classes that are able to generate the HTML text.

Examples at the end show the intended output strings when printed.

## Part A (1p)

Introduce an abstract base class `HTMLElement` with an abstract `str` conversion method.
Have the base class store a `style` member variable, with a `None` default value.
Include a convenience method `style_string` that takes no arguments and returns a string: `'style="xxx"'` if the style value is not `None`, or else just an empty string `''` (if there is no styling).

## Part B (1p)

Add a subclass `Link` that takes an `url` (e.g. `https://www.chalmers.se`), an `element` that goes inside the link (typically the link name), and an optional `style` (default value `None`).

The format for the `Link` output should be
```
<a href="put_url_here">put_element_here</a>
<a href="put_url_here" style="if style exists">put_element_here</a>
```

## Part C (3p)

Several simple text-related HTML blocks are very similar, e.g. `<b>bold</b>`, `<i style="color:red">italic</i>`, which can be combined in various ways.

To save ourselves some coding, implement an abstract class `TextElement` as a subclass of `HTMLElement`. Introduce the new abstract method `tag_name` which must return the name of the HTML tag (`'b'` for bold, `'i'` for italic) 
Implement the `str` conversion.

Constructing any `TextElement` subclass should take `element` and an optional `style` (default value `None`).
In this application, we only wish to allow for the input to `element` to be a `str` or a `TextElement`. Add a check and raise a `ValueError` if someone tries to use something else e.g. (`BoldText(123)`, `ItalicText(Link(url, name))`).

Implement the `TextElement`-subclasses `BoldText` and `ItalicText`


## Part D (2p)

We need some HTML elements that contain multiple other elements.
Create `Paragraph` and `Body` as subclasses to `HTMLElement`. They should both take a list of elements and the optional `style` (default value `None`).

For `Paragraph`, you should simply join the elements with space separation inside a block named `p`:
```html
<p>first_element second_element third_element ...</p>
```

For `Body` (which typically contains a lot), make the output more readable by introducing new lines for each element, indenting it
using 4 spaces inside a block named `body` (see example below).

## Test code

```python
p0 = Paragraph(["Text can be", ItalicText("cursive,"), BoldText("bold"), "or",
                ItalicText(BoldText("both"), style="color:red")])
print("first paragraph as HTML:")
print(p0)
print()
p1 = Paragraph([BoldText("Chalmers"), Link('https://www.chalmers.se', "link", 'color:blue')])
print("second paragraph as HTML:")

print()
body = Body([p0, p1])
print("whole body as HTML:")
print(body)
```
