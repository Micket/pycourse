# DAT171 Object oriented programming in Python

* Prerequisite: Basic programming knowledge in any language
* Learn how to develop code in modern Python, the most popular language today.
* Object oriented programming techniques; learn how to use and design your own data types
* Interactive lecture material using Jupyter notebooks
* 3 assignments (3.0hp)
    * SciPy, Numpy, Matplotlib for the computational foundation
    * Write a python library with object oriented programming paradigm
    * Interactive graphical applications with Model-View-Controller design using Qt
* Computer exam (4.5hp) with Python, documentation, lecture material available
